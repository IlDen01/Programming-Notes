# Корневая оптимизация (Sqrt Decomposition, разбиение на корневые блоки)

## Теория

### Задача

Нужно уметь на массиве быстро делать:

* **запрос**: посчитать $\sum$ на отрезке $[l, r)$
* **обновление**: изменить значение $a_i$

Наивно оба запроса можно сделать за $O(n)$ или $O(1)$ (в зависимости от того, что предподсчитано), но нельзя сделать оба быстрыми одновременно без доп. структуры.

Корневая оптимизация даёт оба запроса за $O(\sqrt{n})$.

---

## Идея

Разбиваем массив на блоки длиной $\approx \sqrt{n}$.

Для каждого блока храним агрегат (в данном случае — сумму элементов блока).

* **обновление элемента** — меняем сам элемент и пересчитываем сумму его блока за $O(1)$
* **запрос на отрезке** — отрезок разбивается на три части:
    * незавершённый левый кусок — проходим поэлементно
    * целиком покрытые блоки — берём готовые суммы блоков
    * незавершённый правый кусок — проходим поэлементно

Так как незавершённых кусков — не больше двух блоков, а целых блоков — не больше $\sqrt{n}$, суммарно получаем $O(\sqrt{n})$.

---

## Инициализация

Индексация 0-based, размер блока — константа.

```c++
constexpr int BLOCK_SIZE = 300;

std::vector<long long> a, block;

void build(int n) {
    int block_quantity = (n + BLOCK_SIZE - 1) / BLOCK_SIZE;
    block.assign(block_quantity, 0);
    for (int i = 0; i < n; i++) {
        block[i / BLOCK_SIZE] += a[i];
    }
}
```

### Объяснение

* `block_quantity` — количество блоков, с округлением вверх (последний блок может быть неполным)
* номер блока элемента `i` — `i / BLOCK_SIZE`
* сумма блока накапливается проходом по всем элементам один раз, за $O(n)$

---

## Обновление элемента

Меняем значение `a[i]` на `val` и обновляем сумму блока на разницу.

```c++
void update(int i, long long val) {
    block[i / BLOCK_SIZE] += val - a[i];
    a[i] = val;
}
```

### Объяснение

* блок пересчитывать целиком не нужно — достаточно скорректировать его сумму на разницу нового и старого значения
* сам массив `a` обязательно храним, так как из него берутся элементы неполных краевых кусков

---

## Запрос суммы на отрезке

Считаем сумму на полуинтервале `[l, r)`.

```c++
long long query(int l, int r) {
    long long ans = 0;
    int lb = (l + BLOCK_SIZE - 1) / BLOCK_SIZE;
    int rb = r / BLOCK_SIZE;

    if (lb >= rb) {
        for (int i = l; i < r; i++) {
            ans += a[i];
        }
        return ans;
    }

    for (int i = l; i < lb * BLOCK_SIZE; i++) {
        ans += a[i];
    }
    for (int i = lb; i < rb; i++) {
        ans += block[i];
    }
    for (int i = rb * BLOCK_SIZE; i < r; i++) {
        ans += a[i];
    }
    return ans;
}
```

### Объяснение

* `lb` — номер первого **полностью** покрытого блока (округление вверх)
* `rb` — номер первого блока, который отрезок уже не покрывает целиком
* если `lb >= rb`, между границами нет ни одного целого блока — отрезок короче блока или укладывается в один блок, считаем его поэлементно
* иначе отрезок распадается на три части:
    * `[l, lb * BLOCK_SIZE)` — хвост первого неполного блока, поэлементно
    * `[lb, rb)` — целые блоки, берём готовые суммы
    * `[rb * BLOCK_SIZE, r)` — начало последнего неполного блока, поэлементно

---

## Асимптотика

* обновление элемента — `O(1)`
* запрос на отрезке — краевые куски дают не больше `2 * BLOCK_SIZE` элементов, целые блоки — не больше `n / BLOCK_SIZE`

```c++
O(BLOCK_SIZE + n / BLOCK_SIZE)
```

Минимум достигается при `BLOCK_SIZE ≈ sqrt(n)`, тогда время запроса — `O(sqrt(n))`.

---

## Применения

* задачи с суммой/минимумом/максимумом на отрезке при частых точечных обновлениях
* Mo's algorithm (разбиение запросов на блоки по левой границе)
* задачи, где нужна структура проще дерева отрезков, а асимптотика `O(sqrt(n))` укладывается в ограничения
* поддержка агрегатов на массиве, когда обновления не сводятся к точечным (например, массовые операции с "ленивым" пересчётом блока целиком)
