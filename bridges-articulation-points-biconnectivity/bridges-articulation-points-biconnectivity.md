# Мосты, точки сочленения и двусвязность (Bridges, Articulation Points, Biconnectivity)

## Теория

### Базовые определения

* **Мост (Bridge)** — ребро, при удалении которого количество компонент связности графа увеличивается.
* **Точка сочленения (Articulation Point / Cut Vertex)** — вершина, при удалении которой количество компонент связности
  графа увеличивается.
* **Компонента реберной двусвязности (КРД)** — максимальный по включению подграф, в котором нет мостов.
* **Компонента вершинной двусвязности (Блок)** — максимальный по включению подграф, в котором нет точек сочленения.

---

## Идея

В основе алгоритмов поиска мостов и точек сочленения лежит обход в глубину (DFS) и построение дерева обхода.

В неориентированном графе рёбра при обходе делятся на два типа:

1. **Древесные рёбра** — по которым прошёл DFS.
2. **Обратные рёбра** — ведущие в уже посещённого предка.

Для каждой вершины `u` мы считаем два значения:

* `depth[u]` — глубина вершины в дереве DFS (расстояние от корня обхода).
* `up[u]` — минимальная глубина среди всех вершин, в которые можно попасть из поддерева `u`, пройдя по древесным рёбрам,
  а затем сделав **не более одного** перехода по обратному ребру.

### Пересчёт `up[u]`

Изначально предполагаем, что выше себя подняться нельзя: `up[u] = depth[u]`. Далее перебираем смежные вершины `v`:

* Если ребро `(u, v)` — обратное (и не ведёт в родителя по дереву DFS), мы нашли путь наверх:
  `up[u] = std::min(up[u], depth[v])`
* Если ребро `(u, v)` — древесное (вызвали `dfs(v)`), то после возврата из рекурсии мы можем использовать пути из
  поддерева:
  `up[u] = std::min(up[u], up[v])`

---

## Поиск мостов

### Критерий моста

Ребро `(u, v)`, по которому мы спустились в DFS, является мостом тогда и только тогда, когда:
$up[v] > depth[u]$

Это означает, что из поддерева вершины `v` нет ни одного обратного ребра, ведущего в саму вершину `u` или её предков.
Следовательно, если удалить ребро `(u, v)`, то в поддерево `v` вернуться будет невозможно.

### Тонкость с кратными рёбрами

Если в графе могут быть кратные рёбра, нельзя просто запрещать переход в родителя по номеру вершины
(`if (v == parent)`). Нужно передавать в DFS идентификатор ребра (`edge_id`), по которому мы пришли в вершину, и
проверять по нему.

---

## Поиск точек сочленения

### Критерий точки сочленения

Вершина `u` является точкой сочленения, если выполняется одно из условий:

1. **`u` — корень дерева DFS** (то есть `depth[u] == 0`), и из неё выходит **больше одного** древесного ребра (DFS
   запускался в её детей более одного раза).
2. **`u` — не корень дерева DFS**, и у неё есть хотя бы один ребёнок `v` в дереве DFS, для которого выполняется:
   $up[v] \ge depth[u]$

---

## Компоненты реберной двусвязности (КРД)

КРД делят **вершины** графа на непересекающиеся множества. Их можно выделить за **один проход** DFS с использованием
стека вершин:

1. Во время спуска в DFS кладём текущую вершину `u` в стек.
2. Когда мы заканчиваем обрабатывать вершину `u`, проверяем условие:
   $up[u] == depth[u]$ это означает, что из поддерева `u` нет обратных рёбер строго выше `u`.
3. Следовательно, ребро, входящее в `u` сверху, является мостом (либо `u` — корень). Все вершины в стеке вплоть до `u`
   образуют одну КРД.
4. Извлекаем их из стека и помечаем единым идентификатором компоненты.

---

## Компоненты вершинной двусвязности (Блоки)

В отличие от КРД, блоки делят **рёбра** графа на непересекающиеся множества (одна вершина-точка сочленения может лежать
в нескольких блоках). Блоки также можно выделить за **один проход** DFS с использованием стека рёбер:

1. При обходе кладём каждое пройденное ребро (древесное или обратное, ведущее вверх) в стек.
2. Когда после возврата из рекурсивного вызова `dfs(v)` выполняется условие точки сочленения:
   $up[v] \ge depth[u]$ это означает, что поддерево `v` и ребро `(u, v)` образуют изолированный блок (или несколько уже
   выделенных блоков внутри).
3. Извлекаем рёбра из стека до тех пор, пока не достанем ребро `(u, v)`. Все эти рёбра принадлежат одному блоку.

---

## Асимптотика

Все описанные алгоритмы (построение массива глубин, пересчёт динамики `up`, поиск мостов, точек сочленения и выделение
компонент) работают за один проход DFS:
$O (V + E)$
Где $V$ — количество вершин, $E$ — количество рёбер.

## Готовая реализация

### 1. Поиск мостов

```c++
std::vector<std::vector<std::pair<int, int>>> g; // g[u] хранит пары {v, edge_id}
std::vector<int> depth, up;
std::vector<bool> used;
std::vector<int> bridges; // сохраняем индексы рёбер-мостов

void dfs_bridges(const int u, const int pid = -1, const int d = 0) {
    used[u] = true;
    depth[u] = up[u] = d;
    
    for (auto [v, id] : g[u]) {
        if (id == pid) {
            continue; // не идем по ребру, по которому пришли
        }
        if (used[v]) {
            up[u] = std::min(up[u], depth[v]); // обратное ребро
        } else {
            dfs_bridges(v, id, d + 1); // древесное ребро
            up[u] = std::min(up[u], up[v]);
            if (up[v] > depth[u]) {
                bridges.push_back(id);
            }
        }
    }
}
```

### 2. Поиск точек сочленения

```c++
std::vector<std::set<int>> g;
std::vector<int> depth, up;
std::vector<bool> used, is_cutpoint;

void dfs_cutpoints(const int u, const int p = -1, const int d = 0) {
    used[u] = true;
    depth[u] = up[u] = d;
    int children = 0;
    
    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        if (used[v]) {
            up[u] = std::min(up[u], depth[v]);
        } else {
            dfs_cutpoints(v, u, d + 1);
            up[u] = std::min(up[u], up[v]);
            if (up[v] >= depth[u] && p != -1) {
                is_cutpoint[u] = true;
            }
            children++;
        }
    }
    if (p == -1 && children > 1) {
        is_cutpoint[u] = true;
    }
}
```

### 3. Выделение компонент реберной двусвязности (КРД) за один проход

```c++
std::vector<int> depth, up, comp;
std::vector<bool> used;
std::vector<int> st; // стек вершин
int comp_count = 0;

void dfs_ebc(int u, int p = -1, int d = 0) {
    used[u] = true;
    depth[u] = up[u] = d;
    st.push_back(u);
    
    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        if (used[v]) {
            up[u] = std::min(up[u], depth[v]);
        } else {
            dfs_ebc(v, u, d + 1);
            up[u] = std::min(up[u], up[v]);
        }
    }
    
    // Если из поддерева нет обратных рёбер выше u, то u - корень новой КРД
    if (up[u] == depth[u]) {
        int cur;
        do {
            cur = st.back();
            st.pop_back();
            comp[cur] = comp_count; // comp[i] - номер КРД для вершины i
        } while (cur != u);
        comp_count++;
    }
}
```

### 4. Выделение компонент вершинной двусвязности (Блоков) за один проход

```c++
std::vector<int> depth, up, block_id;
std::vector<bool> used;
std::vector<int> st; // стек индексов рёбер
int blocks_count = 0;

void dfs_vbc(int u, int pid = -1, int d = 0) {
    used[u] = true;
    depth[u] = up[u] = d;
    
    for (auto [v, id] : g[u]) {
        if (id == pid) {
            continue;
        }
        if (used[v]) {
            up[u] = std::min(up[u], depth[v]);
            // Складываем обратное ребро только когда идем по нему вверх
            if (depth[v] < depth[u]) {
                st.push_back(id);
            }
        } else {
            st.push_back(id); // Складываем древесное ребро
            dfs_vbc(v, id, d + 1);
            up[u] = std::min(up[u], up[v]);
            
            // Если u - точка сочленения для поддерева v (или корень блока)
            if (up[v] >= depth[u]) {
                int cur_edge;
                do {
                    cur_edge = st.back();
                    st.pop_back();
                    block_id[cur_edge] = blocks_count; // block_id[id] - номер блока для ребра id
                } while (cur_edge != id);
                blocks_count++;
            }
        }
    }
}
```
