# LCA (Наименьший общий предок)

## Теория

### Задача

Нужно найти наименьшего общего предка двух вершин в **корневом дереве**.

---

## Решение

### Наивный алгоритм

Посчитаем времена входа и выхода вершин при DFS.

Тогда вершина `v` является предком вершины `u`, если

```c++
tin[v] <= tin[u] && tout[u] <= tout[v]
```

После этого можно подниматься от одной вершины к корню, пока текущая вершина не станет предком другой.

Асимптотика: `O(h)`, где `h` — высота дерева.

---

### Двоичные подъёмы

`up[k][v]` — предок вершины `v` на расстоянии `2^k` вверх.

Также обычно хранят:

* `depth[v]` — глубина вершины
* `tin[v]`, `tout[v]` — времена входа и выхода

---

#### База

```c++
up[0][v] = p[v]
```

Для корня обычно удобно считать:

```c++
up[0][root] = root
```

---

#### Предподсчёт

```c++
for (int k = 1; k <= LOG; k++) {
    for (int v = 0; v < n; v++) {
        up[k][v] = up[k - 1][up[k - 1][v]];
    }
}
```

---

#### Проверка на предка

```c++
bool is_ancestor(int u, int v) {
    return tin[u] <= tin[v] && tout[v] <= tout[u];
}
```

---

#### Нахождение LCA

##### Способ 1

Если одна вершина является предком другой, ответ находится сразу.  
Иначе поднимаем `u` как можно выше, но так, чтобы он всё ещё **не** стал предком `v`.

```c++
int lca(int u, int v) {
    if (is_ancestor(u, v)) {
        return u;
    }
    if (is_ancestor(v, u)) {
        return v;
    }

    for (int k = LOG; k >= 0; k--) {
        if (!is_ancestor(up[k][u], v)) {
            u = up[k][u];
        }
    }

    return up[0][u];
}
```

---

##### Способ 2

Сначала поднимаем более глубокую вершину на одну глубину со второй,  
потом одновременно поднимаем обе вершины вверх.

```c++
int lca(int u, int v) {
    if (depth[u] < depth[v]) {
        std::swap(u, v);
    }

    for (int k = LOG; k >= 0; k--) {
        if (depth[u] - (1 << k) >= depth[v]) {
            u = up[k][u];
        }
    }

    if (u == v) {
        return u;
    }

    for (int k = LOG; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }

    return up[0][u];
}
```

Асимптотика одного запроса: `O(log n)`.

---

### Эйлеров обход

#### Идея

Сделаем эйлеров обход дерева, записывая вершины в массив в процессе DFS.

Тогда LCA двух вершин можно найти как вершину с минимальной глубиной на некотором подотрезке эйлерова обхода.

---

#### Эйлеров обход

* `euler` — массив вершин в порядке эйлерова обхода
* `first[v]` — индекс первого появления вершины `v` в массиве `euler`

При обходе:

* при первом посещении добавляем вершину в `euler`
* после возврата из ребёнка снова добавляем текущую вершину

```c++
void dfs(int v, int p) {
    first[v] = (int)euler.size();
    euler.push_back(v);

    for (int to : g[v]) {
        if (to == p) {
            continue;
        }
        depth[to] = depth[v] + 1;
        dfs(to, v);
        euler.push_back(v);
    }
}
```

Для дерева размер массива обычно равен:

```c++
2 * n - 1
```

---

#### Сведение к RMQ

Построим массив глубин по эйлерову обходу:

```c++
A[i] = depth[euler[i]]
```

Тогда для запроса `lca(u, v)`:

* берём `l = first[u]`, `r = first[v]`
* если `l > r`, меняем их местами
* ищем позицию минимальной глубины на отрезке `A[l..r]`

Тогда:

```c++
lca(u, v) = euler[argmin(A[l..r])]
```

---

#### Sparse Table для RMQ

`st[k][i]` — индекс в массиве `euler`, соответствующий вершине с минимальной глубиной на отрезке длины `2^k`, начинающемся в `i`.

После предобработки можно отвечать на запросы за `O(1)`.

Итоговая асимптотика:

* построение: `O(n log n)`
* один запрос: `O(1)`

---

### Алгоритм Тарьяна (offline LCA)

#### Теория

Дано дерево и набор запросов LCA вида `(u, v)`, причём все запросы известны заранее.

Можно ответить на все запросы одним обходом DFS, используя DSU.

В этом алгоритме используются функции из конспекта по DSU:

* `get(v)`
* `unite(u, v)`

---

#### Идея: DSU + текущий кандидат на LCA

Во время DFS:

* каждая вершина сначала образует свою DSU-компоненту
* после обработки ребёнка объединяем его компоненту с компонентой текущей вершины
* для каждой DSU-компоненты храним вершину `lca_class[rep]` — текущего кандидата на LCA

Также храним:

* `used[u] = true`, если поддерево `u` уже полностью обработано
* `queries[u]` — список запросов, связанных с вершиной `u`
* `ans[id]` — ответ на запрос с номером `id`

---

#### Структуры

* `lca_class[u]` — для представителя DSU хранит текущий ответ-кандидат
* `used[u]` — вершина уже завершена DFS-ом
* `queries[u]` — список пар `(v, id)`
* `ans[id]` — ответ на запрос

Для каждого запроса `(u, v)` нужно добавить его в обе вершины:

```c++
queries[u].push_back({v, id});
queries[v].push_back({u, id});
```

---

#### Решение

Так как в DSU функция `unite(u, v)` ничего не возвращает,  
после объединения нужно брать нового представителя через `get(...)`.

```c++
void dfs(int u, int p = -1) {
    lca_class[u] = u;

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        dfs(v, u);
        unite(u, v);
        lca_class[get(u)] = u;
    }

    used[u] = true;

    for (auto [v, id] : queries[u]) {
        if (used[v]) {
            ans[id] = lca_class[get(v)];
        }
    }
}
```

---

#### Почему это работает

Когда вершина `u` завершает обработку, все вершины её поддерева уже объединены в одну DSU-компоненту,  
и для этой компоненты текущий кандидат на LCA равен `u`.

Если в запросе `(u, v)` вершина `v` уже обработана, значит её поддерево уже завершено,  
и `lca_class[get(v)]` как раз указывает на нужный LCA.

---

#### Асимптотика

Если запросов `m`, то:

* DFS: `O(n)`
* операции DSU: `O((n + m) * α(n))`

Итого:

```c++
O((n + m) * α(n))
```

что на практике почти линейно.

---

## Краткое сравнение методов

### Наивный алгоритм

* просто реализуется
* работает за `O(h)`

### Двоичные подъёмы

* универсальный и очень популярный метод
* построение: `O(n log n)`
* запрос: `O(log n)`

### Эйлеров обход + RMQ

* построение: `O(n log n)`
* запрос: `O(1)`

### Тарьян offline

* подходит, если все запросы известны заранее
* почти линейная суммарная асимптотика
