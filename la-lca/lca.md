# LCA (Lowest Common Ancestor, наименьший общий предок)

## Теория

### Задача

Дано **корневое дерево**. Нужно уметь быстро находить наименьшего общего предка (LCA) двух вершин — самую глубокую вершину, которая является предком обеих.

Что нужно уметь делать:

* по двум вершинам находить их LCA
* проверять, является ли одна вершина предком другой
* при необходимости — отвечать на много таких запросов быстро (в том числе offline)

---

## Идея

Есть несколько способов решения, каждый со своим балансом между временем предподсчёта и временем ответа на запрос:

* **наивный подъём** — подниматься к корню, пока не найдём общего предка
* **двоичные подъёмы** — подъём степенями двойки, аналог sparse table по дереву
* **эйлеров обход + RMQ** — сведение LCA к минимуму на отрезке
* **offline через DSU (алгоритм Тарьяна)** — обработка всех запросов за один DFS

Общие для всех методов величины:

* `depth[v]` — глубина вершины
* `tin[v]`, `tout[v]` — времена входа и выхода при DFS, нужны для проверки "предок ли"

---

## Наивный алгоритм

Вершина `v` является предком вершины `u`, если её интервал `[tin, tout]` содержит интервал `u`:

```c++
tin[v] <= tin[u] && tout[u] <= tout[v]
```

Дальше можно поднимать одну из вершин к корню, пока она не станет предком другой.

### Идея на пальцах

* `tin`/`tout` задают вложенность поддеревьев — как скобочную последовательность
* если отрезок `v` содержит отрезок `u`, значит поддерево `v` содержит `u`
* поднимаемся от `u` вверх, пока условие не выполнится

Асимптотика: `O(h)`, где `h` — высота дерева. В худшем случае (дерево-цепочка) это `O(n)`.

---

## Двоичные подъёмы

`up[k][v]` — предок вершины `v` на расстоянии `2^k` вверх.

### Инициализация

```c++
up[0][v] = p[v];
```

Для корня удобно считать `up[0][root] = root`, чтобы подъём не выходил за пределы дерева.

### Предподсчёт

```c++
for (int k = 1; k <= LOG; k++) {
    for (int v = 0; v < n; v++) {
        up[k][v] = up[k - 1][up[k - 1][v]];
    }
}
```

#### Идея

* это классическое **удвоение**: подъём на `2^k` = два подъёма на `2^(k-1)`
* аналогично построению sparse table для RMQ, только по дереву, а не по массиву

---

### Проверка на предка

```c++
bool is_ancestor(int u, int v) {
    return tin[u] <= tin[v] && tout[v] <= tout[u];
}
```

---

### Нахождение LCA — способ 1

Если одна вершина — предок другой, ответ очевиден. Иначе поднимаем `u` максимально высоко, но так, чтобы он **не** стал предком `v`.

```c++
int lca(int u, int v) {
    if (is_ancestor(u, v)) {
        return u;
    }
    if (is_ancestor(v, u)) {
        return v;
    }

    for (int k = LOG; k >= 0; k--) {
        if (!is_ancestor(up[k][u], v)) {
            u = up[k][u];
        }
    }

    return up[0][u];
}
```

#### Идея на пальцах

* если сразу поднимемся выше LCA — потеряем ответ, поэтому двигаемся "почти до LCA"
* перебираем степени двойки от большей к меньшей — это как двоичный поиск по высоте
* в конце `u` — прямой ребёнок LCA, значит `up[0][u]` и есть LCA

---

### Нахождение LCA — способ 2

Сначала уравниваем глубины вершин, потом поднимаем обе одновременно, пока не встретятся сразу над LCA.

```c++
int lca(int u, int v) {
    if (depth[u] < depth[v]) {
        std::swap(u, v);
    }

    for (int k = LOG; k >= 0; k--) {
        if (depth[u] - (1 << k) >= depth[v]) {
            u = up[k][u];
        }
    }

    if (u == v) {
        return u;
    }

    for (int k = LOG; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }

    return up[0][u];
}
```

#### Идея на пальцах

* сначала выравниваем глубины — теперь `u` и `v` на одном уровне
* если после этого равны — один из них и есть LCA
* иначе поднимаем обе вершины синхронно, но так, чтобы они **не совпали** — иначе можно перепрыгнуть LCA
* в конце `u` и `v` — два разных ребёнка LCA, значит `up[0][u]` и есть ответ

Асимптотика одного запроса: `O(log n)`.

---

## Эйлеров обход + RMQ

### Идея

Сделаем **эйлеров обход** дерева — DFS, где вершина записывается в массив при каждом заходе в неё (включая возврат из детей).

Тогда LCA двух вершин — это вершина с минимальной глубиной на подотрезке эйлерова обхода между их первыми вхождениями.

---

### Построение эйлерова обхода

* `euler` — массив вершин в порядке обхода
* `first[u]` — индекс первого появления `u` в `euler`

```c++
void dfs(const int u, const int p = -1) {
    first[u] = static_cast<int>(euler.size());
    euler.push_back(u);

    for (const int v : g[u]) {
        if (v == p) {
            continue;
        }

        depth[v] = depth[u] + 1;
        dfs(v, u);
        euler.push_back(u);
    }
}
```

#### Идея на пальцах

* при первом заходе в вершину — записываем её
* после возврата из каждого ребёнка — снова записываем текущую вершину
* размер массива для дерева из `n` вершин: `2 * n - 1`

---

### Сведение к RMQ

Строим массив глубин по обходу:

```c++
A[i] = depth[euler[i]];
```

Для запроса `lca(u, v)`:

```c++
l = first[u], r = first[v];
if (l > r) std::swap(l, r);
lca(u, v) = euler[argmin(A[l..r])];
```

#### Идея на пальцах

* между первыми вхождениями `u` и `v` в обходе лежит весь путь от одного к другому через LCA
* самая "верхняя" (минимальная по глубине) вершина на этом пути — и есть LCA

---

### Sparse Table для RMQ

`st[k][i]` — индекс в `euler`, где достигается минимальная глубина на отрезке длины `2^k`, начинающемся в `i`.

Строится стандартно, как sparse table на минимум, только хранит индексы, а не сами значения.

Асимптотика:

* построение: `O(n log n)`
* один запрос: `O(1)`

---

## Offline LCA (алгоритм Тарьяна)

### Теория

Дано дерево и набор запросов `(u, v)`, все запросы известны заранее. Можно ответить на все за один обход DFS с помощью **DSU** (функции `get`, `unite` из конспекта по DSU).

---

### Идея

Во время DFS:

* каждая вершина изначально — своя DSU-компонента
* после обработки поддерева ребёнка — объединяем его компоненту с компонентой текущей вершины
* для каждой DSU-компоненты храним `lca_class[rep]` — текущего кандидата на LCA
* `used[u]` — true, если поддерево `u` полностью обработано
* `queries[u]` — список пар `(v, id)` запросов, связанных с `u`
* `ans[id]` — ответ на запрос номер `id`

Для запроса `(u, v)` добавляем его в обе вершины:

```c++
queries[u].push_back({v, id});
queries[v].push_back({u, id});
```

---

### Решение

`unite(u, v)` ничего не возвращает, поэтому после объединения берём представителя через `get(...)`.

```c++
void dfs(int u, int p = -1) {
    lca_class[u] = u;

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        dfs(v, u);
        unite(u, v);
        lca_class[get(u)] = u;
    }

    used[u] = true;

    for (auto [v, id] : queries[u]) {
        if (used[v]) {
            ans[id] = lca_class[get(v)];
        }
    }
}
```

### Идея на пальцах

* когда `u` завершает обработку, всё его поддерево уже объединено в одну DSU-компоненту
* кандидат на LCA для этой компоненты — сама вершина `u`
* если в запросе `(u, v)` вершина `v` уже обработана (её поддерево завершено), значит `lca_class[get(v)]` указывает на нужный LCA — общий предок, который "выше" обеих

---

## Асимптотика

* наивный подъём: запрос — `O(h)`
* двоичные подъёмы: построение — `O(n log n)`, запрос — `O(log n)`
* эйлеров обход + sparse table: построение — `O(n log n)`, запрос — `O(1)`
* offline Тарьян: суммарно `O((n + m) * α(n))` на `m` запросов — почти линейно

---

## Применения

* задачи на расстояния между вершинами дерева (`dist(u, v) = depth[u] + depth[v] - 2 * depth[lca(u, v)]`)
* k-й предок вершины (двоичные подъёмы используются отдельно)
* offline-обработка большого числа запросов на дереве
* деревья отрезков на дереве, LCA в дереве Кактала / Suffix Tree
* проверка принадлежности пути одному поддереву

---

## Готовая реализация

```c++
std::vector<int> depth, tin, tout, first_occ, euler;
std::vector<std::vector<int>> up, g;
int LOG, timer_ = 0;

void dfs(int v, int p) {
    tin[v] = timer_++;
    up[0][v] = p;
    first_occ[v] = (int)euler.size();
    euler.push_back(v);

    for (int to : g[v]) {
        if (to == p) {
            continue;
        }
        depth[to] = depth[v] + 1;
        dfs(to, v);
        euler.push_back(v);
    }

    tout[v] = timer_++;
}

void precompute(int n) {
    for (int k = 1; k <= LOG; k++) {
        for (int v = 0; v < n; v++) {
            up[k][v] = up[k - 1][up[k - 1][v]];
        }
    }
}

bool is_ancestor(int u, int v) {
    return tin[u] <= tin[v] && tout[v] <= tout[u];
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) {
        std::swap(u, v);
    }

    for (int k = LOG; k >= 0; k--) {
        if (depth[u] - (1 << k) >= depth[v]) {
            u = up[k][u];
        }
    }

    if (u == v) {
        return u;
    }

    for (int k = LOG; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }

    return up[0][u];
}

// offline LCA через DSU (алгоритм Тарьяна)
std::vector<int> parents, sizes, lca_class, ans;
std::vector<bool> used;
std::vector<std::vector<std::pair<int, int>>> queries;

int get(const int v) {
    if (v == parents[v]) {
        return v;
    }
    return parents[v] = get(parents[v]);
}

void unite(int u, int v) {
    u = get(u), v = get(v);
    if (u == v) {
        return;
    }
    if (sizes[u] < sizes[v]) {
        std::swap(u, v);
    }
    parents[v] = u;
    sizes[u] += sizes[v];
}

void tarjan_dfs(int u, int p = -1) {
    lca_class[u] = u;

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        tarjan_dfs(v, u);
        unite(u, v);
        lca_class[get(u)] = u;
    }

    used[u] = true;

    for (auto [v, id] : queries[u]) {
        if (used[v]) {
            ans[id] = lca_class[get(v)];
        }
    }
}
```
