# LA (Level Ancestor, предок на уровне)

## Теория

### Задача

Нужно найти предка вершины `v`, который находится на `k` рёбер выше.

Иначе говоря, нужно найти `k`-го предка вершины.

Эквивалентная формулировка: найти предка вершины `v` на заданной глубине.

---

## Решение

### Наивный алгоритм

Если для каждой вершины хранится её непосредственный предок `p[v]`, то можно `k` раз подняться вверх по дереву.

```c++
while (k > 0) {
    v = p[v];
    k--;
}
```

Асимптотика одного запроса:

```c++
O(k)
```

В худшем случае это `O(n)`.

---

### Двоичные подъёмы

Это тот же подход, что и в [LCA](lca.md).

`up[k][v]` — предок вершины `v` на расстоянии `2^k` вверх.

Также обычно хранят:

* `depth[v]` — глубина вершины

---

#### База

```c++
up[0][v] = p[v]
```

Для корня обычно удобно считать:

```c++
up[0][root] = root
```

---

#### Предподсчёт

Обычно таблица `up` строится во время DFS.

```c++
const int LOG = 20;

std::vector<std::vector<int>> g, up;
std::vector<int> depth;

void dfs(int v, int p = 0) {
    up[0][v] = p;

    for (int k = 1; k <= LOG; k++) {
        up[k][v] = up[k - 1][up[k - 1][v]];
    }

    for (int to : g[v]) {
        if (to == p) {
            continue;
        }
        depth[to] = depth[v] + 1;
        dfs(to, v);
    }
}
```

Если вершины нумеруются с `0`, то часто корнем выбирают `0` и запускают:

```c++
dfs(0, 0);
```

---

#### Нахождение `k`-го предка

Разложим число `k` по степеням двойки.

Если в двоичной записи `k` стоит бит `i`, то нужно подняться на `2^i` вверх.

```c++
int la(int v, int k) {
    if (k > depth[v]) {
        return -1;
    }

    for (int i = 0; i <= LOG; i++) {
        if (k & (1 << i)) {
            v = up[i][v];
        }
    }

    return v;
}
```

---

#### Нахождение предка на заданной глубине

Если нужно найти предка вершины `v` на глубине `target_depth`,
то достаточно подняться на

```c++
depth[v] - target_depth
```

вверх.

```c++
int la_depth(int v, int target_depth) {
    if (target_depth < 0 || target_depth > depth[v]) {
        return -1;
    }

    return la(v, depth[v] - target_depth);
}
```

---

#### Почему это работает

Любое число `k` можно представить в виде суммы степеней двойки:

```c++
k = 2^a1 + 2^a2 + ...
```

Тогда можно последовательно сделать несколько прыжков вверх:

* на `2^a1`
* на `2^a2`
* ...

Суммарно получится подъём ровно на `k` рёбер.

---

## Асимптотика

### Двоичные подъёмы

* построение: `O(n log n)`
* один запрос: `O(log n)`
* память: `O(n log n)`

---

## Связь с LCA

Таблица `up[k][v]` используется не только в задаче LA, но и в LCA.

Фактически LA — это более простая задача:

* в LA нужно поднять одну вершину вверх на известное число рёбер
* в LCA нужно найти точку, где пути двух вершин к корню впервые пересекаются

Во многих задачах функция

```c++
la(v, k)
```

используется как вспомогательная внутри более сложных алгоритмов на деревьях.

---

## Применения

LA часто используется в задачах на:

* `k`-го предка вершины
* подъём вершины до заданной глубины
* двоичные подъёмы
* LCA
* запросы на деревьях

---

## Готовая реализация

```c++
const int LOG = 20;

std::vector<std::vector<int>> g, up;
std::vector<int> depth;

void dfs(int v, int p = 0) {
    up[0][v] = p;

    for (int k = 1; k <= LOG; k++) {
        up[k][v] = up[k - 1][up[k - 1][v]];
    }

    for (int to : g[v]) {
        if (to == p) {
            continue;
        }
        depth[to] = depth[v] + 1;
        dfs(to, v);
    }
}

int la(int v, int k) {
    if (k > depth[v]) {
        return -1;
    }

    for (int i = 0; i <= LOG; i++) {
        if (k & (1 << i)) {
            v = up[i][v];
        }
    }

    return v;
}

int la_depth(int v, int target_depth) {
    if (target_depth < 0 || target_depth > depth[v]) {
        return -1;
    }

    return la(v, depth[v] - target_depth);
}
```

---

### Лестничная декомпозиция (Алгоритм $O(1)$ на запрос)

#### Идея

Мы можем ответить на запрос `la(v, k)` за $O(1)$, если скомбинируем две вещи:
1. **Двоичные подъёмы:** позволяют одним прыжком преодолеть *больше половины* пути.
2. **Декомпозицию на длинные пути (лестницы):** позволяет дойти оставшийся "хвостик" пути за $O(1)$ с помощью обычного обращения к массиву.

#### Как это работает (теория)

1. Разобьём дерево на непересекающиеся **вертикальные пути**. Для этого из каждой вершины всегда будем идти в того ребёнка, у которого глубина поддерева максимальна.
2. Корень каждого такого пути назовём `head`.
3. Пусть длина пути от `head` до нижнего листа равна $L$. Продлим этот путь **вверх** (к корню дерева) ровно на $L$ вершин. Получившаяся структура длиной $2L$ называется **лестницей** (ladder).
4. **Магия прыжка:**
    * Пусть нам нужно прыгнуть на $k$ шагов вверх. Найдём максимальную степень двойки $p \le k$ (например, $p = 2^{\lfloor \log_2 k \rfloor}$).
    * Прыгнем на $p$ шагов с помощью двоичных подъёмов: `u = up[log][v]`.
    * Нам осталось прыгнуть $rem = k - p$ шагов. Мы знаем, что $rem < p$.
    * Поскольку мы пришли в вершину `u` снизу, пройдя $p$ шагов, длина максимального пути из `u` вниз **как минимум** $p$. Значит, длина всего пути, на котором лежит `u`, тоже $\ge p$.
    * А так как мы продлили путь вверх на его длину, лестница покрывает как минимум $p$ шагов вверх от `head`. Значит, нужный нам предок **гарантированно** лежит в массиве этой лестницы!

---

#### Предподсчёт

Нам понадобятся массивы для путей вниз и лестниц вверх, а также указатель на `head` для каждой вершины.

```c++
const int LOG = 20;

std::vector<std::vector<int>> g, up;
std::vector<int> depth, max_depth, head;
std::vector<std::vector<int>> path, ladder;

// DFS 1: Считаем глубины, max_depth и двоичные подъёмы
void dfs1(int v, int p = 0) {
    up[0][v] = p;
    for (int k = 1; k <= LOG; k++) {
        up[k][v] = up[k - 1][up[k - 1][v]];
    }

    max_depth[v] = depth[v];
    for (int to : g[v]) {
        if (to != p) {
            depth[to] = depth[v] + 1;
            dfs1(to, v);
            max_depth[v] = std::max(max_depth[v], max_depth[to]);
        }
    }
}

// DFS 2: Строим пути и лестницы
void dfs2(int v, int p, int h) {
    head[v] = h;
    path[h].push_back(v); // Добавляем вершину в путь вниз

    int heavy_child = -1;
    for (int to : g[v]) {
        if (to != p) {
            if (heavy_child == -1 || max_depth[to] > max_depth[heavy_child]) {
                heavy_child = to;
            }
        }
    }

    if (heavy_child != -1) {
        dfs2(heavy_child, v, h); // Продолжаем текущий путь
    }

    for (int to : g[v]) {
        if (to != p && to != heavy_child) {
            dfs2(to, v, to); // Начинаем новые пути из лёгких детей
        }
    }
}

// Вызывать перед ответами на запросы:
void build(int root, int n) {
    dfs1(root, root);
    dfs2(root, root, root);

    // Строим лестницы вверх для каждого head
    for (int i = 0; i < n; i++) {
        if (head[i] == i) { // Если вершина — начало пути
            int curr = i;
            int len = path[i].size(); // Длина пути вниз L
            
            // Поднимаемся на L шагов вверх (или до корня)
            for (int j = 0; j < len; j++) {
                ladder[i].push_back(curr);
                curr = up[0][curr];
            }
        }
    }
}
```

---

#### Нахождение $k$-го предка за $O(1)$

В C++ можно найти старший бит числа $k$ (логарифм) за $O(1)$ с помощью функции `std::__lg(k)`.

```c++
int la_O1(int v, int k) {
    if (k > depth[v]) return -1;
    if (k == 0) return v;

    // 1. Делаем большой прыжок
    int lg = std::__lg(k);
    int u = up[lg][v];
    
    // 2. Считаем, сколько шагов осталось
    int rem = k - (1 << lg);
    if (rem == 0) return u;

    // 3. Находим нужную вершину в пути или лестнице
    int h = head[u];
    int dist_to_head = depth[u] - depth[h];

    if (rem <= dist_to_head) {
        // Мы всё ещё ниже head, идём по пути вниз
        return path[h][dist_to_head - rem];
    } else {
        // Мы поднимаемся выше head, идём по лестнице вверх
        return ladder[h][rem - dist_to_head];
    }
}
```

---

#### Асимптотика Лестничной декомпозиции

* **Предподсчёт:** $O(n \log n)$ времени и памяти (из-за двоичных подъёмов). Сами лестницы и пути занимают суммарно не более $2n$ памяти.
* **Время запроса:** $O(1)$. Нет никаких циклов, только битовые операции и обращения по индексу к массивам.

#### Где применяется
Это идеальный алгоритм для задач, где **число запросов огромно** (например, $10^7$ запросов при дереве из $10^5$ вершин), и метод с двоичными подъёмами (дающий $O(q \log n)$) не проходит по времени.
