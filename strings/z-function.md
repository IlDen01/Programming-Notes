# Z-функция (Z-function)

## Теория

### Задача

Для строки `s` длины `n` нужно за линейное время посчитать массив `z`, где:

* `z[i]` — длина наибольшего общего префикса строки `s` и её суффикса, начинающегося с позиции `i`
* по определению `z[0]` не определён (или полагается равным `0`, `n`, — по соглашению)

Z-функция позволяет быстро искать вхождения одной строки в другую, находить периоды строки и решать другие задачи на совпадения подстрок.

---

## Идея

Ключевая идея — поддерживать **z-блок** `[l, r]` — самый правый по правой границе отрезок, совпадающий с префиксом строки, среди уже обработанных.

* `l` — левая граница текущего z-блока
* `r` — правая граница текущего z-блока (не включая саму `r`, либо включая — зависит от реализации; здесь `r` не включается)

Инвариант:

* `s[l..r) == s[0..r-l)`
* при переходе к очередной позиции `i` используем уже посчитанные значения `z`, чтобы не начинать сравнение с нуля

---

## Вычисление Z-функции

```c++
std::vector<int> zFunction(const std::string& s) {
    int n = s.size();
    std::vector<int> z(n, 0);
    int l = 0, r = 0;

    for (int i = 1; i < n; i++) {
        if (i < r) {
            z[i] = std::min(r - i, z[i - l]);
        }
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) {
            z[i]++;
        }
        if (i + z[i] > r) {
            l = i;
            r = i + z[i];
        }
    }

    return z;
}
```

### Идея на пальцах

* если `i` лежит внутри текущего z-блока (`i < r`), то часть ответа уже известна:
    * позиции `i` в блоке соответствует позиция `i - l` в префиксе
    * значит `z[i]` не меньше, чем `min(r - i, z[i - l])` — это стартовая нижняя оценка
* дальше пытаемся **досчитать** сравнение посимвольно, начиная с этой позиции, а не с нуля
* если удалось продвинуть границу дальше `r` — обновляем блок `[l, r]` на новый, более правый
* каждый символ строки "сдвигает" правую границу `r` только вперёд, поэтому суммарно она двигается не больше `n` раз

---

## Асимптотика

* построение Z-функции — `O(n)`
* амортизация работает за счёт того, что правая граница блока `r` монотонно не убывает и увеличивается максимум `n` раз за весь проход

```c++
O(n)
```

---

## Применения

* поиск подстроки в строке (конкатенация `паттерн + разделитель + текст`, ищем `z[i] == len(паттерн)`)
* подсчёт числа различных подстрок
* нахождение всех периодов строки
* сжатие строк, построение автоматов
* сравнение строки с её сдвигами / циклическими сдвигами

## Задача: период строки

Потсроим z-функцию. k — период, если `z[k] = n - k`.

---

## Задача: количество различных подстрок строки

Идея: количество различных подстрок строки `s` длины `n` равно сумме "новых" подстрок, добавляемых на каждом префиксе.

Для каждого префикса `s[0..i)` переворачиваем его и считаем Z-функцию. Максимальное значение Z-функции (кроме нулевой позиции) — это длина наибольшего суффикса нового символа, который уже встречался раньше как префикс. Значит новых подстрок, оканчивающихся на позиции `i-1`, ровно `i - max(z)`.

```c++
long long countDistinctSubstrings(const std::string& s) {
    int n = s.size();
    long long result = 0;

    for (int i = 1; i <= n; i++) {
        std::string prefix = s.substr(0, i);
        std::reverse(prefix.begin(), prefix.end());

        std::vector<int> z = zFunction(prefix);
        int maxZ = 0;
        for (int j = 1; j < i; j++) {
            maxZ = std::max(maxZ, z[j]);
        }

        result += i - maxZ;
    }

    return result;
}
```

### Идея на пальцах

* добавляя очередной символ, строка `s[0..i)` порождает `i` новых суффиксов (по одному для каждой длины от `1` до `i`)
* часть этих суффиксов уже встречалась раньше как подстрока — это как раз те суффиксы, которые **совпадают с каким-то более ранним префиксом** текущего перевёрнутого куска
* переворачивая префикс, превращаем задачу "суффикс совпадает с более ранней подстрокой" в задачу "префикс перевёрнутой строки совпадает с её же подстрокой, начинающейся правее" — то есть в обычную Z-функцию
* максимум Z-функции по перевёрнутому префиксу — длина самого длинного суффикса, который **уже был** раньше
* значит новых подстрок на этом шаге: `i - maxZ`
* суммируем по всем `i` от `1` до `n`

---

## Асимптотика

* пересчёт Z-функции на каждом шаге — `O(i)`, суммарно по всем `i` — `O(n^2)`

```c++
O(n^2)
```

* можно ускорить до `O(n log n)` с помощью суффиксного массива или до `O(n)` с суффиксным автоматом, но через Z-функцию — квадратичное решение
