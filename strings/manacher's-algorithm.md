# Алгоритм Манакера (Manacher's algorithm)

## Теория

### Задача

Нужно для каждой позиции строки найти длину максимального палиндрома с центром в этой позиции.

Манакер умеет находить:

* длины всех палиндромов нечётной длины (центр — символ)
* длины всех палиндромов чётной длины (центр — между символами)

за линейное время, что позволяет решать:

* поиск всех палиндромных подстрок
* поиск максимального палиндрома в строке
* подсчёт количества палиндромных подстрок

---

## Идея

Считаем два массива:

* `d1[i]` — количество палиндромов нечётной длины с центром в `i` (включая тривиальный длины 1)
* `d2[i]` — количество палиндромов чётной длины с центром между `i-1` и `i`

Ключевая идея — **переиспользование уже посчитанной информации**.

Пока мы двигаемся по строке, храним границы `[l, r]` — самый правый из найденных палиндромов.

Если текущая позиция `i` лежит внутри `[l, r]`, то у неё есть симметричная позиция относительно центра этого палиндрома — из неё можно взять готовую нижнюю оценку и не начинать расширение с нуля.

---

## Нечётные палиндромы

``` c++
std::vector<int> d1(n);
for (int i = 0, l = 0, r = -1; i < n; i++) {
    int k = (i > r) ? 1 : std::min(d1[l + r - i], r - i + 1);
    while (i - k >= 0 && i + k < n && s[i - k] == s[i + k]) {
        k++;
    }
    d1[i] = k;
    if (i + k - 1 > r) {
        l = i - k + 1;
        r = i + k - 1;
    }
}
```

### Объяснение

* `l, r` — границы самого правого известного палиндрома
* если `i` вне `[l, r]` — начинаем расширение с `k = 1`
* если `i` внутри `[l, r]` — берём **зеркальную позицию** `l + r - i` и её значение `d1[]` как стартовую оценку, но не больше, чем расстояние до границы `r`
* дальше пытаемся расширить палиндром вручную, сравнивая символы
* если новый палиндром вылез за `r` — обновляем границы

---

## Чётные палиндромы

``` c++
std::vector<int> d2(n);
for (int i = 0, l = 0, r = -1; i < n; i++) {
    int k = (i > r) ? 0 : std::min(d2[l + r - i + 1], r - i + 1);
    while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k]) {
        k++;
    }
    d2[i] = k;
    if (i + k - 1 > r) {
        l = i - k;
        r = i + k - 1;
    }
}
```

### Объяснение

* логика та же, что для `d1`, но центр палиндрома сдвинут между `i-1` и `i`
* сравнение символов идёт по индексам `i - k - 1` и `i + k`
* зеркальная позиция берётся как `l + r - i + 1` из-за сдвига центра

---

## Максимальный палиндром в строке

По `d1` и `d2` длина палиндрома с центром в `i`:

* нечётный: `2 * d1[i] - 1`
* чётный: `2 * d2[i]`

``` c++
int best = 1;
for (int i = 0; i < n; i++) {
    best = std::max(best, 2 * d1[i] - 1);
    best = std::max(best, 2 * d2[i]);
}
```

---

## Асимптотика

``` c++
O(n)
```

* границы `r` монотонно не убывают на протяжении всего прохода
* каждое сравнение символов в `while` либо расширяет `r`, либо сразу завершается
* суммарное число расширений ограничено `n`, значит весь проход линейный

---

## Применения

* поиск всех палиндромных подстрок
* поиск наибольшего палиндрома в строке
* подсчёт количества палиндромных подстрок
* задачи на разбиение строки на палиндромы (в связке с DP)
