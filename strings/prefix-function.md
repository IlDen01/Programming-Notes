# Префиксная функция (Prefix Function, Z-функция Кнута-Морриса-Пратта)

## Теория

### Задача

Для строки `s` длины `n` нужно для каждой позиции `i` найти длину наибольшего собственного суффикса подстроки `s[0..i]`, который одновременно является её префиксом.

Префикс-функция используется, когда нужно:

* искать вхождения одной строки в другой (алгоритм КМП)
* находить периоды и бордеры строки
* сжимать строку (нахождение минимального периода)
* считать количество различных подстрок вида "циклический сдвиг"

---

## Идея

**Префикс-функция** `pi[i]` — длина наибольшего **бордера** подстроки `s[0..i]` (бордер — строка, которая одновременно является и префиксом, и суффиксом, и не равна всей строке).

Ключевая идея вычисления за `O(n)`:

* значения `pi[i]` и `pi[i-1]` связаны — при переходе от `i-1` к `i` не нужно пересчитывать всё заново
* если `s[i]` продолжает бордер длины `pi[i-1]`, увеличиваем его
* если нет — "откатываемся" по цепочке бордеров более короткой подстроки, используя уже посчитанные `pi`

---

## Вычисление префикс-функции

```c++
std::vector<int> prefix_function(const std::string& s) {
    int n = s.size();
    std::vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j]) {
            j = pi[j - 1];
        }
        if (s[i] == s[j]) {
            j++;
        }
        pi[i] = j;
    }
    return pi;
}
```

### Как это работает

* `j` — кандидат на длину нового бордера, стартуем от `pi[i-1]` (лучший бордер предыдущей позиции)
* если символ `s[i]` не продолжает текущий бордер — сокращаем его до **бордера бордера**, то есть `j = pi[j-1]`
* так делаем, пока не найдём подходящий бордер или не дойдём до `j == 0`
* если символ совпал — бордер увеличивается на 1
* `pi[0]` всегда равен `0` (у подстроки из одного символа нет собственного бордера)

---

## Поиск подстроки (алгоритм КМП)

Чтобы найти все вхождения строки `t` (шаблон) в строку `s` (текст), склеиваем `t + '#' + s` (символ-разделитель, не встречающийся в строках) и считаем префикс-функцию результата.

```c++
std::vector<int> find_occurrences(const std::string& t, const std::string& s) {
    std::string combined = t + '#' + s;
    std::vector<int> pi = prefix_function(combined);
    std::vector<int> result;
    int m = t.size();

    for (int i = m + 1; i < (int)combined.size(); i++) {
        if (pi[i] == m) {
            result.push_back(i - 2 * m);
        }
    }
    return result;
}
```

### Как это работает

* разделитель `#` не даёт бордеру "перепрыгнуть" через границу шаблона и текста
* если в какой-то позиции `pi[i] == m` (длина шаблона), значит там закончилось вхождение `t`
* индекс начала вхождения в исходном `s` — это `i - 2 * m` (вычитаем длину шаблона и разделитель)

---

## Поиск периода строки

**Период** строки `s` длины `n` — число `k`, такое что `s[i] == s[i + k]` для всех допустимых `i`. Строка называется периодической, если её период `k < n`.

```c++
int min_period(const std::string& s) {
    int n = s.size();
    std::vector<int> pi = prefix_function(s);
    int k = n - pi[n - 1];
    return k;
}
```

### Как это работает

* `pi[n-1]` — длина наибольшего бордера всей строки
* граница бордера — это "перекрытие" начала и конца строки, а величина `n - pi[n-1]` — минимальный сдвиг, при котором строка накладывается сама на себя
* этот сдвиг `k = n - pi[n-1]` — кандидат на **минимальный период** строки
* если `n` делится на `k` нацело — строка **полностью периодична** с периодом `k` (состоит из целого числа повторений блока длины `k`)
* если `n` не делится на `k` — строка не периодична полностью, но `k` всё равно остаётся минимальным сдвигом самоперекрытия (иногда называют это "неполным" или "предпериодом")

Проверка на полную периодичность:

```c++
bool is_periodic(const std::string& s) {
    int n = s.size();
    int k = min_period(s);
    return n % k == 0;
}
```

## Количество различных подстрок

Идея: обрабатывать строку слева направо, поддерживая **развёрнутый (reversed) префикс** уже обработанной части. На каждом шаге новый символ `s[i]` дописывается **в начало** развёрнутой строки, после чего считается префикс-функция и по ней — число новых подстрок.

```c++
long long count_distinct_substrings(const std::string& s) {
    int n = s.size();
    long long result = 0;
    std::string reversed_prefix;

    for (int i = 0; i < n; i++) {
        reversed_prefix = s[i] + reversed_prefix;
        std::vector<int> pi = prefix_function(reversed_prefix);
        int max_pi = *std::max_element(pi.begin(), pi.end());
        result += reversed_prefix.size() - max_pi;
    }
    return result;
}
```

### Как это работает

* `reversed_prefix` — это строка `s[0..i]`, записанная **в обратном порядке** (реверс текущего префикса)
* добавление `s[i]` в начало `reversed_prefix` эквивалентно добавлению `s[i]` в конец `s[0..i]` с последующим разворотом всей строки
* все суффиксы строки `s[0..i]` (оканчивающиеся в позиции `i`) соответствуют **префиксам** строки `reversed_prefix`
* значение `pi[k]` в `reversed_prefix` означает: префикс длины `k+1` этой строки уже встречался раньше как её подстрока — то есть соответствующий суффикс `s[0..i]` **не новый**, он уже встречался в `s` раньше
* берём **максимум** префикс-функции по всей строке `reversed_prefix` — это длина самого длинного суффикса `s[0..i]`, который уже был подстрокой ранее
* тогда число новых подстрок, заканчивающихся в позиции `i`, равно `длина строки - максимум pi`
* суммируя эту величину по всем `i` от `0` до `n-1`, получаем общее количество различных подстрок строки `s`

---

## Асимптотика

* вычисление префикс-функции — `O(n)`
* амортизация: указатель `j` суммарно за весь проход увеличивается не больше `n` раз, а каждое уменьшение (откат) списывает одно из этих увеличений
* поиск подстроки через КМП — `O(n + m)`, где `n` — длина текста, `m` — длина шаблона
* поиск периода — `O(n)`, так как сводится к одному вычислению префикс-функции
* подсчёт различных подстрок — `O(n^2)`, так как на каждом из `n` шагов пересчитывается префикс-функция строки длины до `n`

---

## Применения

* поиск подстроки в строке (КМП)
* нахождение всех бордеров строки (цепочка `pi[i], pi[pi[i]-1], ...`)
* нахождение минимального периода строки: `n - pi[n-1]` (если делит `n`, это точный период)
* сжатие строки при циклических сдвигах
* подсчёт числа различных подстрок в строке
* автомат КМП для сравнения строк за `O(1)` на переход
