# DSU (Disjoint Set Union, система непересекающихся множеств)

## Теория

### Задача

Нужно поддерживать разбиение элементов на непересекающиеся множества и уметь:

* узнать, в каком множестве находится элемент
* проверить, лежат ли два элемента в одном множестве
* объединить два множества

DSU хорошо подходит, когда нужно динамически объединять компоненты связности.

---

## Идея

Каждое множество представляется деревом.

Для каждой вершины хранится:

* `parents[v]` — родитель вершины
* `sizes[v]` — размер множества, если `v` является корнем

Корень дерева является представителем множества.

Если `parents[v] == v`, то `v` — корень своей компоненты.

---

## Инициализация

Изначально каждый элемент находится в своём собственном множестве.

```c++
std::vector<int> parents, sizes;

for (int i = 0; i < n; i++) {
    parents[i] = i;
    sizes[i] = 1;
}
```

После этого:

* у каждого элемента свой представитель
* размер каждого множества равен `1`

---

## Нахождение представителя

Функция `get(v)` возвращает представителя множества, в котором находится вершина `v`.

```c++
int get(const int v) {
    if (v == parents[v]) {
        return v;
    }
    return parents[v] = get(parents[v]);
}
```

### Сжатие путей

Здесь используется **сжатие путей**.

Когда мы ищем корень вершины `v`, мы рекурсивно поднимаемся вверх.  
После этого всем вершинам на пути сразу записываем найденный корень.

Это ускоряет дальнейшие запросы.

---

## Объединение множеств

Функция `unite(u, v)` объединяет множества, в которых лежат `u` и `v`.

```c++
void unite(int u, int v) {
    u = get(u), v = get(v);
    if (u == v) {
        return;
    }
    if (sizes[u] < sizes[v]) {
        std::swap(u, v);
    }
    parents[v] = u;
    sizes[u] += sizes[v];
}
```

### Эвристика по размеру

Здесь используется **объединение по размеру**:

* сначала находим корни обоих множеств
* если множества уже совпадают, ничего делать не нужно
* меньшее дерево подвешиваем к большему

Это помогает не допускать сильного роста высоты дерева.

---

## Проверка на одну компоненту

Чтобы проверить, лежат ли `u` и `v` в одном множестве, достаточно проверить:

```c++
get(u) == get(v)
```

---

## Асимптотика

При использовании:

* сжатия путей
* объединения по размеру

амортизированное время одной операции равно:

```c++
O(α(n))
```

где `α(n)` — обратная функция Аккермана, которая растёт очень медленно.  
На практике это почти константа.

---

## Применения

DSU часто используется в задачах на:

* компоненты связности
* объединение множеств
* алгоритм Краскала
* offline-обработку запросов
* поиск связных компонент в динамике, если есть только добавление рёбер
