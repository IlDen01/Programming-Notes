# Heavy-Light декомпозиция

## Теория

Для подвешенного дерева, для каждой вершины рассмотрим всех ее детей. Для каждого ребенка посчитаем размер его
поддерева. Ребро, которое ведет к ребенку с самым большим поддеревом, назовем _тяжелым_, а остальные ребра — _легкими._

Таким образом дерево распалось на тяжелые и легкие ребра. Такое разбиение и называется **heavy-light декомпозицией**.

### Свойства heavy-light декомпозиции

1. Дерево разбивается на непересекающиеся пути из тяжелых ребер.
2. На любом вертикальном пути не более $O(\log n)$ блоков.
3. На любом пути не более $O(\log n)$ блоков.
