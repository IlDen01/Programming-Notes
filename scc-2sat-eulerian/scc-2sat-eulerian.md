# Strong connected components, 2-SAT, Eulerian (Компоненты сильной связности, 2-SAT, Эйлеровость)

## Теория

### Компоненты сильной связности (КСС)

В ориентированном графе нужно уметь:

* находить множества вершин, где из каждой вершины достижима любая другая (в обе стороны)
* сжимать граф в **конденсацию** — ациклический граф из КСС
* использовать конденсацию для offline-обработки запросов на ориентированном графе

### 2-SAT

Дана булева формула в виде конъюнкции дизъюнктов по 2 литерала:

```c++
(x1 ∨ x2) ∧ (¬x1 ∨ x3) ∧ ...
```

Нужно уметь:

* проверить, существует ли набор значений переменных, при котором формула истинна
* если существует — построить его

### Эйлеровость

В графе (ориентированном или неориентированном) нужно уметь:

* проверить, существует ли **эйлеров цикл** (обход всех рёбер, возврат в начало)
* проверить, существует ли **эйлеров путь** (обход всех рёбер без возврата)
* построить сам обход

---

## Идея

### КСС (алгоритм Косарайю)

* два обхода DFS
* первый — на исходном графе, чтобы получить порядок выхода из вершин (постпорядок)
* второй — на транспонированном графе (все рёбра развёрнуты), в порядке убывания времени выхода
* каждое дерево DFS во втором обходе — это одна КСС

### КСС (алгоритм Тарьяна)

* один обход DFS, без транспонирования графа
* для каждой вершины хранится время входа `tin[v]` и **минимальная достижимая метка** `up[v]`
* все вершины текущей КСС держим на стеке
* если у корня поддерева `up[v] == tin[v]` — он корень своей КСС, снимаем стек до него

### 2-SAT через КСС

* каждая переменная `x` — две вершины: `x` и `¬x`
* дизъюнкт `(a ∨ b)` эквивалентен импликациям `¬a → b` и `¬b → a`
* строим граф импликаций, ищем КСС
* формула выполнима, если ни для одной переменной `x` и `¬x` не лежат в одной КСС
* значение `x` берём по тому, чья КСС **позже** в топологическом порядке конденсации (`x`, если КСС(x) после КСС(¬x))

### Эйлеров цикл/путь

* строится жадным обходом с удалением рёбер (алгоритм Хиерхольцера)
* инвариант: если зашли в вершину по ребру и не можем выйти — эта вершина попадает в ответ, идём назад по стеку
* условия существования проверяются заранее по степеням вершин

---

## КСС: инициализация и первый DFS (Косарайю)

Обходим граф, записываем вершины в порядке выхода из рекурсии.

```c++
std::vector<std::vector<int>> g, gt;
std::vector<bool> used;
std::vector<int> order, comp;

void dfs1(int v) {
    used[v] = true;
    for (int to : g[v]) {
        if (!used[to]) {
            dfs1(to);
        }
    }
    order.push_back(v);
}
```

### Идея

* постпорядок гарантирует: вершина, из которой ничего больше не достижимо, выходит первой
* корень «финальной» КСС конденсации выйдет последним

---

## КСС: второй DFS по транспонированному графу (Косарайю)

```c++
void dfs2(int v, int c) {
    comp[v] = c;
    for (int to : gt[v]) {
        if (comp[to] == -1) {
            dfs2(to, c);
        }
    }
}

void find_scc(int n) {
    used.assign(n, false);
    comp.assign(n, -1);
    for (int v = 0; v < n; v++) {
        if (!used[v]) {
            dfs1(v);
        }
    }
    std::reverse(order.begin(), order.end());
    int c = 0;
    for (int v : order) {
        if (comp[v] == -1) {
            dfs2(v, c++);
        }
    }
}
```

### Идея

* идём по вершинам в порядке убывания времени выхода из первого DFS
* каждый новый DFS по `gt` красит ровно одну КСС
* так получаем компоненты плюс их **топологический порядок** (по возрастанию `c`)

---

## КСС: алгоритм Тарьяна (однопроходный)

Находит КСС за один DFS, без построения транспонированного графа.

```c++
std::vector<std::vector<int>> g;
std::vector<int> tin, up, comp;
std::vector<bool> on_stack;
std::stack<int> st;
int timer = 0, comp_count = 0;

void tarjan_dfs(int u) {
    tin[u] = up[u] = timer++;
    st.push(u);
    on_stack[u] = true;
    for (int v : g[u]) {
        if (tin[v] == -1) {
            tarjan_dfs(v);
            up[u] = std::min(up[u], up[v]);
        } else if (on_stack[v]) {
            up[u] = std::min(up[u], tin[v]);
        }
    }
    if (up[u] == tin[u]) {
        while (true) {
            int v = st.top();
            st.pop();
            on_stack[v] = false;
            comp[v] = comp_count;
            if (v == u) {
                break;
            }
        }
        comp_count++;
    }
}

void find_scc_tarjan(int n) {
    tin.assign(n, -1);
    up.assign(n, -1);
    comp.assign(n, -1);
    on_stack.assign(n, false);
    for (int i = 0; i < n; i++) {
        if (tin[i] == -1) {
            tarjan_dfs(i);
        }
    }
}
```

### Идея

* `up[v]` — минимальный `tin` вершины, достижимой из поддерева `v` по рёбрам вперёд или **назад к вершине на стеке**
* на стеке лежат только вершины, ещё не отнесённые ни к одной завершённой КСС
* переход к `to` учитывается в `up[v]` только если `to` сейчас на стеке — иначе это ребро в уже готовую КСС, его нужно игнорировать
* если `up[v] == tin[v]` — вершина `v` корень своей КСС, всё, что выше неё на стеке, снимается и красится в эту компоненту
* компоненты нумеруются в порядке, **обратном** топологическому (в отличие от Косарайю)

---

## 2-SAT: построение графа импликаций

Для переменной `i` вершина `2*i` — это `xi`, вершина `2*i+1` — это `¬xi`.

```c++
void add_clause(int a, bool na, int b, bool nb) {
    int x = 2 * a + na, nx = 2 * a + !na;
    int y = 2 * b + nb, ny = 2 * b + !nb;
    g[nx].push_back(y);
    g[ny].push_back(x);
}
```

### Идея

* дизъюнкт `(a ∨ b)` — это `¬a → b` и `¬b → a`
* каждое ребро — импликация: если левая часть истинна, то и правая должна быть истинна

---

## 2-SAT: проверка выполнимости и восстановление ответа

```c++
bool solve_2sat(int n, std::vector<bool>& answer) {
    find_scc(2 * n);
    for (int i = 0; i < n; i++) {
        if (comp[2 * i] == comp[2 * i + 1]) {
            return false;
        }
        answer[i] = comp[2 * i] > comp[2 * i + 1];
    }
    return true;
}
```

### Идея

* если `x` и `¬x` в одной КСС — они одновременно истинны и ложны, противоречие
* иначе берём переменную равной той литере, чья КСС стоит позже в топологическом порядке
* это гарантирует согласованность со всеми импликациями
* **важно**: при использовании Тарьяна нумерация компонент обратная — условие нужно менять на `answer[i] = comp[2 * i] < comp[2 * i + 1]`

---

## Эйлеров цикл: проверка существования

```c++
bool has_euler_cycle(int n, std::vector<std::vector<int>>& g) {
    for (int v = 0; v < n; v++) {
        if (g[v].size() % 2 != 0) {
            return false;
        }
    }
    return true;
}
```

### Идея

* для неориентированного графа: эйлеров цикл существует, если все степени чётные
* граф должен быть связным по рёбрам (компонента с рёбрами — одна)

---

## Эйлеров цикл: построение (алгоритм Хиерхольцера)

```c++
std::vector<std::vector<std::pair<int,int>>> g;
std::vector<bool> used_edge;
std::vector<int> euler_path;

void euler_dfs(int u) {
    while (!g[u].empty()) {
        auto [v, id] = g[u].back();
        g[u].pop_back();
        if (used_edge[id]) {
            continue;
        }
        used_edge[id] = true;
        euler_dfs(v);
    }
    euler_path.push_back(u);
}
```

### Идея

* идём по рёбрам, пока есть куда идти, помечаем рёбра использованными
* когда застряли — вершина точно замыкает часть цикла, кладём её в ответ
* итоговый `euler_path` в перевёрнутом порядке — искомый обход
* работает и для эйлерова пути: стартуем из вершины с нечётной степенью (если такие есть ровно две)

---

## Асимптотика

* КСС (Косарайю): два DFS по графу — `O(V + E)`
* КСС (Тарьян): один DFS, каждая вершина и ребро обрабатываются один раз — `O(V + E)`
* 2-SAT: построение графа `O(V + E)`, КСС `O(V + E)` — суммарно `O(V + E)`
* Эйлеров обход (Хиерхольцера): каждое ребро используется один раз — `O(V + E)`

---

## Применения

* КСС:
    * построение конденсации графа
    * offline-запросы на ориентированном графе
    * поиск циклов, анализ зависимостей
    * Тарьян предпочтителен, когда нужен один проход и не хочется строить транспонированный граф (например, в задачах с ограничением по памяти)
* 2-SAT:
    * задачи с булевыми ограничениями «выбери один из двух вариантов»
    * расписания, конфликтующие условия
* Эйлеровость:
    * задачи на обход всех дорог/рёбер без повторов
    * восстановление последовательности (например, задача о доминошках)

---

std::vector<std::vector<int>> g, gt;
std::vector<bool> used;
std::vector<int> order, comp;

void dfs1(int v) {
    used[v] = true;
    for (int to : g[v]) {
        if (!used[to]) {
            dfs1(to);
        }
    }
    order.push_back(v);
}

void dfs2(int v, int c) {
    comp[v] = c;
    for (int to : gt[v]) {
        if (comp[to] == -1) {
            dfs2(to, c);
        }
    }
}

void find_scc(int n) {
    used.assign(n, false);
    comp.assign(n, -1);
    for (int v = 0; v < n; v++) {
        if (!used[v]) {
            dfs1(v);
        }
    }
    std::reverse(order.begin(), order.end());
    int c = 0;
    for (int v : order) {
        if (comp[v] == -1) {
            dfs2(v, c++);
        }
    }

// ===== КСС (Тарьян, однопроходный) =====
std::vector<int> tin, up;
std::vector<bool> on_stack;
std::stack<int> st_tarjan;
int timer_t = 0, comp_count_t = 0;

void tarjan_dfs(int v) {
    tin[v] = up[v] = timer_t++;
    st_tarjan.push(v);
    on_stack[v] = true;
    for (int to : g[v]) {
        if (tin[to] == -1) {
            tarjan_dfs(to);
            up[v] = std::min(up[v], up[to]);
        } else if (on_stack[to]) {
            up[v] = std::min(up[v], tin[to]);
        }
    }
    if (up[v] == tin[v]) {
        while (true) {
            int u = st_tarjan.top();
            st_tarjan.pop();
            on_stack[u] = false;
            comp[u] = comp_count_t;
            if (u == v) {
                break;
            }
        }
        comp_count_t++;
    }
}

void find_scc_tarjan(int n) {
    tin.assign(n, -1);
    up.assign(n, -1);
    comp.assign(n, -1);
    on_stack.assign(n, false);
    for (int v = 0; v < n; v++) {
        if (tin[v] == -1) {
            tarjan_dfs(v);
        }
    }
}

// ===== 2-SAT =====
void add_clause(int a, bool na, int b, bool nb) {
    int x = 2 * a + na, nx = 2 * a + !na;
    int y = 2 * b + nb, ny = 2 * b + !nb;
    g[nx].push_back(y);
    g[ny].push_back(x);
}

bool solve_2sat(int n, std::vector<bool>& answer) {
    find_scc(2 * n);
    for (int i = 0; i < n; i++) {
        if (comp[2 * i] == comp[2 * i + 1]) {
            return false;
        }
        answer[i] = comp[2 * i] > comp[2 * i + 1];

    return true;
}

std::vector<std::vector<std::pair<int,int>>> ge;
std::vector<bool> used_edge;
std::vector<int> euler_path;

void euler_dfs(int u) {

        auto [v, id] = ge[u].back();

}
