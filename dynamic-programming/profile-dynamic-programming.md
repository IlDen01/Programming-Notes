# ДП по профилю (Profile Dynamic Programming, динамика по профилю)

## Теория

Задача: посчитать число способов замостить прямоугольную доску `n × m` доминошками (`1×2` и `2×1`), без пропусков и наложений.

Нужно уметь:

* посчитать количество полных замощений доски фигурами фиксированной формы
* (обобщается на доски с запрещёнными клетками и на другие наборы фигур)

Стандартное ограничение: `m < 10`, чтобы маска состояния строки/столбца помещалась в `int` (`2^m` состояний).

---

## Идея

Доска заполняется постепенно. В любой момент часть клеток уже замощена, часть — нет. Граница между замощённой и незамощённой частью называется **профилем**.

Профиль кодируется битовой маской длины `m`: бит равен `1`, если соответствующая клетка на границе уже накрыта плиткой, "высунувшейся" из уже обработанной части доски.

Два способа обхода доски дают два вида профиля:

* **прямой профиль** — двигаемся по столбцам целиком; профиль — прямая вертикальная линия между столбцами
* **изломанный профиль** — двигаемся по отдельным клеткам (по строке слева направо, затем следующая строка); профиль — ломаная линия "лесенкой"

Изломанный профиль сложнее представить, зато его пересчёт **гораздо дешевле**: не нужно перебирать все совместимые пары масок, достаточно двух переходов на клетку.

---

## ДП по прямому профилю

### Описание

* `dp[i][mask]` — число способов замостить первые `i` столбцов так, что в столбец `i` "высовываются" плитки согласно маске `mask`
* переход от столбца к столбцу: перебираем все пары `(prev, next)`, совместимые между собой (корректно продолжающие мозаику)

### Код

```c++
dp[0][0] = 1;
for (int i = 0; i < n; i++) {
    for (int prev = 0; prev < (1 << m); prev++) {
        if (!dp[i][prev]) continue;
        for (int next : g[prev]) {
            add(dp[i + 1][next], dp[i][prev]);
        }
    }
}
```

### Объяснение

* `dp[0][0] = 1` — до начала доска пуста, ничего не торчит в первый столбец
* `g[prev]` — заранее посчитанный список масок `next`, совместимых с `prev`
* совместимость проверяется по каждой из `m` строк независимо:
  * `prev=0, next=0` — в этой строке новая горизонтальная плитка (или клетка свободна и ждёт соседа)
  * `prev=1, next=0` — плитка, пришедшая из прошлого столбца, здесь заканчивается
  * `prev=0, next=1` — начинается вертикальная плитка, торчащая в следующий столбец
  * `prev=1, next=1` — недопустимая комбинация для доминошек
* на каждую строку — не больше **3** допустимых локальных комбинаций → всего до `3^m` совместимых пар `(prev, next)` на переход между столбцами

## ДП по изломанному профилю

### Описание

* обходим доску по клеткам: `i = 0 .. n*m - 1`, клетка `i` соответствует `(row, col) = (i / m, i % m)`
* `dp[i][mask]` — число способов замостить первые `i` клеток так, что `mask` описывает, какие из следующих `m` клеток (текущий профиль) уже заняты плитками, поставленными раньше
* на каждом шаге либо клетка `i` уже занята — просто сдвигаем маску, либо клетку нужно чем-то закрыть — горизонтальной или вертикальной плиткой

### Код

```c++
void add(long long& a, long long b) {
    a = (a + b) % MOD;
}

dp[0][0] = 1;
for (int i = 0; i < n * m; i++) {
    for (int mask = 0; mask < (1 << m); mask++) {
        if (!dp[i][mask]) continue;

        if (mask & 1) {
            add(dp[i + 1][mask >> 1], dp[i][mask]);
            continue;
        }

        if (i % m + 1 < m && !(mask & 2))
            add(dp[i + 1][(mask >> 1) | 1], dp[i][mask]);

        if (i + m < n * m)
            add(dp[i + 1][(mask >> 1) | (1 << (m - 1))], dp[i][mask]);
    }
}
```

### Объяснение

* если `dp[i][mask] == 0` — таких состояний не существует, пропускаем
* `mask & 1 == 1`: клетка `i` уже покрыта плиткой из предыдущей строки — плитку ставить не нужно, просто сдвигаем маску на 1 бит вправо (профиль продвинулся на клетку дальше), `continue`
* иначе клетка `i` свободна, нужно закрыть её плиткой:
  * **горизонтальная** (клетки `i` и `i+1`): можно поставить, если `i` не последняя в строке (`i % m + 1 < m`) и клетка `i+1` ещё не занята (бит `1` маски `= 0`); в новой маске после сдвига выставляем младший бит — клетка `i+1` теперь занята
  * **вертикальная** (клетки `i` и `i+m`): можно поставить, если клетка `i+m` существует (`i + m < n*m`); в новой маске выставляем старший бит `(m-1)` — именно клетка `i+m` окажется на этой позиции профиля через `m` шагов
* `add` — отдельная функция, чтобы сразу брать остаток по модулю

---

## Асимптотика

| Метод | Сложность | Обоснование |
|---|---|---|
| Прямой профиль | `O(n · 3^m)` | `n` столбцов, на каждый — до `3^m` совместимых пар `(prev, next)` |
| Изломанный профиль | `O(n · m · 2^m)` | `n·m` клеток, на каждую — перебор `2^m` масок, `O(1)` переходов |

Изломанный профиль асимптотически выгоднее прямого при том же `m` — не нужно перебирать пары масок, только сами маски.

---

## Применения

* подсчёт числа полных замощений прямоугольной доски доминошками и другими фигурами
* задачи на укладку плитки/паркета с ограничениями
* доски с запрещёнными клетками ("дырками")
* подсчёт числа независимых множеств на сеточных графах
* база для более сложных профильных ДП (гамильтоновы пути/циклы на сетке, TSP на решётке)

## Готовая реализация

```c++
long long dp[N * M + 1][1 << M];
int n, m;

void add(long long& a, long long b) {
    a = (a + b) % MOD;
}

int main() {
    dp[0][0] = 1;
    for (int i = 0; i < n * m; i++) {
        for (int mask = 0; mask < (1 << m); mask++) {
            if (!dp[i][mask]) continue;

            if (mask & 1) {
                add(dp[i + 1][mask >> 1], dp[i][mask]);
                continue;
            }

            if (i % m + 1 < m && !(mask & 2))
                add(dp[i + 1][(mask >> 1) | 1], dp[i][mask]);

            if (i + m < n * m)
                add(dp[i + 1][(mask >> 1) | (1 << (m - 1))], dp[i][mask]);
        }
    }
    // ответ: dp[n * m][0]
}
```
