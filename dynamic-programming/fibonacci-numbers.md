# Числа Фибоначчи за O(log n) (Fibonacci numbers, матричное возведение в степень)

## Теория

### Задача

Нужно быстро находить `n`-е число Фибоначчи при больших `n` (например, `n ~ 10^18`).

Наивная рекуррента `F(n) = F(n-1) + F(n-2)` считается за `O(n)`, что слишком медленно.

Нужно уметь:

* находить `F(n)` за `O(log n)`
* при необходимости — по модулю `mod`

---

## Идея

Рекуррента Фибоначчи переписывается в виде матричного умножения.

Ключевое соотношение:

```c++
[F(n+1)]   [1 1] [F(n)  ]
[F(n)  ] = [1 0] [F(n-1)]
```

Отсюда:

```c++
[1 1]^n   [F(n+1) F(n)  ]
[1 0]   = [F(n)   F(n-1)]
```

То есть `F(n)` — это элемент матрицы `M^n`, где `M = [[1,1],[1,0]]`.

Возведение матрицы в степень делается **быстрым возведением в степень** (аналог `binpow`), что даёт `O(log n)`.

---

## Умножение матриц

Базовая операция — умножение двух матриц `2x2`.

```c++
using Matrix = std::array<std::array<long long, 2>, 2>;

Matrix multiply(const Matrix& a, const Matrix& b, long long mod) {
    Matrix c{};
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 2; k++) {
                c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % mod;
            }
        }
    }
    return c;
}
```

### Что происходит

* обычное матричное умножение `2x2 * 2x2`
* результат сразу берётся по модулю, чтобы не переполнить `long long`
* размер матрицы фиксирован, поэтому все циклы — константные (`O(1)` на умножение)

---

## Быстрое возведение матрицы в степень

```c++
Matrix matrix_pow(Matrix base, long long n, long long mod) {
    Matrix result = {{{1, 0}, {0, 1}}};
    while (n > 0) {
        if (n & 1) {
            result = multiply(result, base, mod);
        }
        base = multiply(base, base, mod);
        n >>= 1;
    }
    return result;
}
```

### Идея бинарного возведения

* начинаем с единичной матрицы (аналог `1` в обычном `binpow`)
* раскладываем степень `n` по битам
* если очередной бит установлен — домножаем ответ на текущую степень `base`
* `base` на каждом шаге возводится в квадрат

Это стандартный **binpow**, применённый к матрицам вместо чисел.

---

## Нахождение F(n)

```c++
long long fibonacci(long long n, long long mod) {
    if (n == 0) {
        return 0;
    }
    Matrix base = {{{1, 1}, {1, 0}}};
    Matrix result = matrix_pow(base, n - 1, mod);
    return result[0][0];
}
```

### Что происходит

* базовый случай `F(0) = 0` обрабатывается отдельно
* для `n >= 1` считаем `M^(n-1)`
* по формуле выше `F(n)` — это элемент `[0][0]` матрицы `M^(n-1)` (то есть `F(n)` в позиции `F(n+1)` для степени `n-1`)

---

## Асимптотика

* умножение двух матриц `2x2` — `O(1)`
* количество умножений в быстром возведении в степень — `O(log n)`

Итоговая сложность:

```c++
O(log n)
```

по времени, `O(1)` по памяти.

---

## Применения

* быстрый счёт чисел Фибоначчи по модулю при больших `n`
* линейные рекурренты произвольного порядка (обобщение на матрицы большего размера)
* подсчёт количества путей длины `n` в графе (матрица смежности в степени `n`)
* решение линейных рекуррентных соотношений вида `f(n) = a*f(n-1) + b*f(n-2) + ...`

---

## Готовая реализация

```c++
using Matrix = std::array<std::array<long long, 2>, 2>;

Matrix multiply(const Matrix& a, const Matrix& b, long long mod) {
    Matrix c{};
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 2; k++) {
                c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % mod;
            }
        }
    }
    return c;
}

Matrix matrix_pow(Matrix base, long long n, long long mod) {

            result = multiply(result, base, mod);
        }
        base = multiply(base, base, mod);
        n >>= 1;

}

long long fibonacci(long long n, long long mod) {

```
