# Динамическое программирование (Dynamic Programming, ДП)

## Теория

ДП — метод решения задач через разбиение на подзадачи, которые пересекаются между собой, с сохранением уже посчитанных результатов.

Чтобы построить ДП, нужно ответить на пять вопросов:

* **что храним** — что означает состояние `dp[...]`
* **база** — значения на тривиальных подзадачах
* **переходы** — как получить `dp[state]` из более простых состояний
* **порядок пересчёта** — в каком порядке считать состояния, чтобы зависимости уже были посчитаны
* **где ответ** — из каких состояний собирается финальный ответ

---

## Идея

Задача разбивается на подзадачи так, чтобы:

* подзадачи пересекались (иначе это просто рекурсия/разделяй-и-властвуй)
* каждая подзадача считалась один раз

Тип состояния зависит от структуры задачи:

* **на подотрезках** — состояние описывает отрезок `[l, r]`
* **по поддеревьям** — состояние описывает вершину дерева, считается от листьев к корню
* **по подмаскам** — состояние описывает подмножество элементов (маску)

---

## ДП на подотрезках

Состояние `dp[l][r]` описывает решение задачи на подотрезке `[l, r]`. Пересчитывается по возрастанию длины отрезка, так как `dp[l][r]` зависит от более коротких отрезков внутри `[l, r]`.

### Задача 1. Количество палиндромных подстрок

Дана строка `s`. Нужно посчитать количество подстрок-палиндромов.

* что храним: `dp[l][r] = true`, если `s[l..r]` — палиндром
* база: `dp[i][i] = true`, `dp[i][i+1] = (s[i] == s[i+1])`
* переход: `dp[l][r] = (s[l] == s[r]) && dp[l+1][r-1]`
* порядок: по возрастанию длины отрезка
* ответ: сумма всех `dp[l][r] == true`

```c++
std::vector<std::vector<bool>> dp(n, std::vector<bool>(n, false));

for (int i = 0; i < n; i++) {
    dp[i][i] = true;
    if (i + 1 < n) {
        dp[i][i + 1] = (s[i] == s[i + 1]);
    }
}

for (int len = 3; len <= n; len++) {
    for (int l = 0; l + len - 1 < n; l++) {
        int r = l + len - 1;
        dp[l][r] = (s[l] == s[r]) && dp[l + 1][r - 1];
    }
}

long long ans = 0;
for (int l = 0; l < n; l++) {
    for (int r = l; r < n; r++) {
        ans += dp[l][r];
    }
}
```

### Объяснение

* палиндром длины `len` получается из палиндрома длины `len - 2`, если совпадают крайние символы
* база — отрезки длины `1` и `2`, дальше их разложить некуда
* считаем строго по возрастанию длины: `dp[l][r]` использует `dp[l+1][r-1]`, у которого длина на `2` меньше

---

### Задача 2. Число корневых деревьев по эйлерову обходу

Дана строка `s` длины `n` (буквы — метки рёбер). Нужно посчитать число корневых деревьев, эйлеров обход которых (по рёбрам) равен `s`.

`dp[l][r]` — количество способов разбить подстроку `s[l..r)` (полуинтервал) на последовательность поддеревьев одного родителя.

* первый ребёнок — подстрока `s[l..k)`, где `k - 1` — позиция возврата по тому же ребру (`s[k-1] == s[l]`)
* внутри первого ребёнка рекурсивно разбирается `s[l+1..k-1)` — его собственные дети
* остаток `s[k..r)` — остальные дети родителя

```c++
std::vector<std::vector<long long>> dp(n + 1, std::vector<long long>(n + 1, 0));

for (int l = 0; l <= n; l++) {
    dp[l][l] = 1;
}

for (int len = 2; len <= n; len++) {
    for (int l = 0; l + len <= n; l++) {
        int r = l + len;
        for (int k = l + 2; k <= r; k++) {
            if (s[k - 1] != s[l]) continue;
            dp[l][r] += dp[l + 1][k - 1] * dp[k][r];
        }
    }
}

// ответ: dp[0][n]
```

### Объяснение

* база — пустая подстрока разбирается ровно одним способом (нет детей)
* перебираем позицию `k`, где заканчивается первый ребёнок (по совпадению метки ребра `s[l] == s[k-1]`)
* количество способов для `[l, r)` — произведение количества способов для первого ребёнка и для остальных детей, просуммированное по всем `k`

## ДП по поддеревьям

Состояние `dp[v]` считается через состояния детей `v`. Обход — dfs от листьев к корню.

### Задача 3. Сумма длин всех путей из корня

Дано дерево. Нужно посчитать сумму расстояний от корня до всех остальных вершин.

* `size[v]` — размер поддерева `v`
* `dp[v]` — сумма расстояний от `v` до всех вершин в его поддереве

```c++
std::vector<int> sz(n, 1);
std::vector<long long> dp(n, 0);

void dfs(int v, int p) {
    for (int u : g[v]) {
        if (u == p) continue;
        dfs(u, v);
        sz[v] += sz[u];
        dp[v] += dp[u] + sz[u];
    }
}
```

### Объяснение

* каждая вершина `u` из поддерева ребёнка `v` находится на `1` дальше от `v`, чем от самого ребёнка — отсюда `+ sz[u]` за каждую вершину поддерева
* `dp[v]` собирается суммированием вкладов всех детей

---

### Задача 4. Корень дерева с минимальным весом

Вес корня `v`: $w[v] = \sum_u w_u \cdot dist(v, u)$. Нужно найти корень с минимальным весом.

* `sumw[v]` — сумма весов вершин в поддереве `v`
* пересчёт при переносе корня вдоль ребра `v → u`: каждая вершина поддерева `u` становится на `1` ближе, все остальные — на `1` дальше

```c++
long long total_w, best = LLONG_MAX;
std::vector<long long> sumw(n), w_dist(n);

void get_sumw(int v, int p) {
    sumw[v] = w[v];
    for (int u : g[v]) {
        if (u == p) continue;
        get_sumw(u, v);
        sumw[v] += sumw[u];
    }
}

void get_root_dp(int v, int p, long long depth_sum) {
    w_dist[v] += depth_sum * w[v];
    for (int u : g[v]) {
        if (u == p) continue;
        get_root_dp(u, v, depth_sum + 1);
    }
}

long long cur; // dp текущего корня

void dfs(int v, int p) {
    best = std::min(best, cur);
    for (int u : g[v]) {
        if (u == p) continue;
        cur += total_w - 2 * sumw[u];
        dfs(u, v);
        cur -= total_w - 2 * sumw[u];
    }
}
```

### Объяснение

* при переносе корня из `v` в ребёнка `u`: вершины поддерева `u` (суммарный вес `sumw[u]`) стали ближе на `1`, остальные (вес `total_w - sumw[u]`) — дальше на `1`
* изменение веса: `+ (total_w - sumw[u]) - sumw[u] = total_w - 2 * sumw[u]`
* `cur` пересчитывается на лету при спуске и восстанавливается при возврате — отдельный массив под `dp` не нужен

## ДП по подмаскам

Состояние `dp[mask]` описывает подмножество элементов. Число состояний — `2^n`, поэтому применимо только при малых `n` (обычно `n ≤ 20`).

### Задача 5. Гамильтонов путь минимального веса

`dp[mask][v]` — минимальный вес пути по вершинам из `mask`, заканчивающегося в `v`.

* база: `dp[1 << v][v] = 0`
* переход: `dp[mask | (1 << u)][u] = min(dp[mask][v] + dist[v][u])` для `u ∉ mask`

```c++
const long long INF = 1e18;
std::vector<std::vector<long long>> dp(1 << n, std::vector<long long>(n, INF));

for (int v = 0; v < n; v++) {
    dp[1 << v][v] = 0;
}

for (int mask = 1; mask < (1 << n); mask++) {
    for (int v = 0; v < n; v++) {
        if (!(mask & (1 << v)) || dp[mask][v] == INF) continue;
        for (int u = 0; u < n; u++) {
            if (mask & (1 << u)) continue;
            dp[mask | (1 << u)][u] = std::min(dp[mask | (1 << u)][u], dp[mask][v] + dist[v][u]);
        }
    }
}

long long ans = INF;
for (int v = 0; v < n; v++) {
    ans = std::min(ans, dp[(1 << n) - 1][v]);
}
```

### Объяснение

* `mask` — уже посещённые вершины, `v` — последняя посещённая
* к пути добавляется новая вершина `u`, не входящая в `mask`
* ответ — минимум по всем `v` при `mask`, равном полному множеству

---

### Задача 6. Максимальная клика

Клика — подмножество вершин, попарно связанных рёбрами. `dp[mask] = true`, если `mask` — клика.

```c++
std::vector<bool> dp(1 << n, false);
dp[0] = true;

for (int mask = 1; mask < (1 << n); mask++) {
    int v = __builtin_ctz(mask);
    int sub = mask ^ (1 << v);
    dp[mask] = dp[sub] && ((adj[v] & sub) == sub);
}

int best = 0;
for (int mask = 0; mask < (1 << n); mask++) {
    if (dp[mask]) {
        best = std::max(best, __builtin_popcount(mask));
    }
}
```

### Объяснение

* `adj[v]` — битовая маска соседей вершины `v`
* берём младший бит `v` из `mask`, убираем его — получаем `sub`
* `mask` — клика, если `sub` — клика **и** `v` смежна со всеми вершинами `sub`

---

### Задача 7. Минимальное число рюкзаков вместимости `W`

Есть `n` предметов с весами `w_i`. Нужно узнать минимальное число рюкзаков вместимости `W`, чтобы унести все предметы.

* `sum[mask]` — суммарный вес предметов в `mask`
* `dp[mask]` — минимальное число рюкзаков, чтобы унести предметы из `mask`
* перебор всех подмасок `mask` — состояние `sub` укладывается в один рюкзак, если `sum[sub] ≤ W`

```c++
std::vector<long long> sum(1 << n, 0);
for (int mask = 1; mask < (1 << n); mask++) {
    int v = __builtin_ctz(mask);
    sum[mask] = sum[mask ^ (1 << v)] + w[v];
}

const int INF = 1e9;
std::vector<int> dp(1 << n, INF);
dp[0] = 0;

for (int mask = 1; mask < (1 << n); mask++) {
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
        if (sum[sub] <= W) {
            dp[mask] = std::min(dp[mask], dp[mask ^ sub] + 1);
        }
    }
}

// ответ: dp[(1 << n) - 1]
```

### Объяснение

* перебор подмасок `sub` внутри `mask` — стандартный приём `for (sub = mask; sub > 0; sub = (sub - 1) & mask)`
* если `sub` укладывается в один рюкзак, оставшиеся предметы `mask ^ sub` докладываются оптимально по уже посчитанному `dp`
* итоговая сложность перебора подмасок — `O(3^n)`, так как каждый элемент независимо лежит в трёх состояниях: не в `mask`, в `mask \ sub`, в `sub`

## Meet in the middle

Идея: если `n` слишком велико для `2^n` (например `n ≤ 40`), но допускает `2^{n/2}`, элементы делятся на две половины, для каждой перебираются все подмножества, а затем результаты половин комбинируются.

### Пример: подсчёт подмножеств с заданной суммой

* делим элементы на две половины по `n/2`
* для каждой половины считаем все суммы подмножеств
* сортируем суммы второй половины
* для каждой суммы первой половины бинарным поиском находим подходящие суммы второй

```c++
std::vector<long long> sums_left, sums_right;

void gen(const std::vector<long long>& a, std::vector<long long>& out) {
    int m = a.size();
    for (int mask = 0; mask < (1 << m); mask++) {
        long long s = 0;
        for (int i = 0; i < m; i++) {
            if (mask & (1 << i)) s += a[i];
        }
        out.push_back(s);
    }
}

// gen(left_half, sums_left);
// gen(right_half, sums_right);
// std::sort(sums_right.begin(), sums_right.end());

long long count_with_sum(long long target) {
    long long cnt = 0;
    for (long long s : sums_left) {
        cnt += std::upper_bound(sums_right.begin(), sums_right.end(), target - s)
             - std::lower_bound(sums_right.begin(), sums_right.end(), target - s);
    }
    return cnt;
}
```

### Объяснение

* полный перебор `2^n` заменяется на два перебора `2^{n/2}`, что на порядки быстрее
* объединение половин — обычно через сортировку и бинарный поиск, реже через хеш-таблицу

---

## Асимптотика

* **на подотрезках**: `O(n^2)` состояний, переход до `O(n)` → итог `O(n^2)`–`O(n^3)` в зависимости от задачи
* **по поддеревьям**: `O(n)` состояний, переход `O(1)` (кроме передачи корня, которая тоже амортизированно `O(n)`) → итог `O(n)`
* **по подмаскам**: `O(2^n)` состояний, переход `O(n)` или `O(2^n)` (при переборе подмасок — суммарно `O(3^n)`)
* **meet in the middle**: $O(2^{n/2} \log(2^{n/2}))$ вместо `O(2^n)`

---

## Применения

* **на подотрезках**: задачи на строки (палиндромы, парсинг скобочных последовательностей), задачи на отрезки массива (оптимальные разбиения, matrix chain multiplication)
* **по поддеревьям**: подсчёт статистик на дереве, техника **пересадки корня** (reroot), задачи на расстояния/суммы в дереве
* **по подмаскам**: задачи с малым `n` и экспоненциальным перебором (коммивояжёр, покрытия, клики), часто как база для дальнейшей оптимизации
* **meet in the middle**: подмножества с ограничением на сумму/вес, задачи NP-сложные при большом `n`, но допускающие `n ≤ 40`
